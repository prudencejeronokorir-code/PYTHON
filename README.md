# PYTHON
Python Practicals
1. Arithmetic Operators
 - Basic mathematical calculations, including multiplication (*) and division (/).

2. Assignment & Update Operators
 - Assigning values (=) and modifying variables in place.

 - Incrementing (+=), decrementing (-=), multiplying and assigning (*=), and dividing and assigning (/=).

3. Comparison Operators
 - Evaluating conditions and returning boolean values.

 - Greater than (>), greater than or equal to (>=), and equality (==).

4. Logical Operators
 - Combining multiple boolean expressions using and, or, and not.

 - Handled debugging scenarios like a NameError when a variable (e.g., is_student) is referenced before definition.

5. Bitwise Operators
 - Performing bitwise operations on integers.

 - Bitwise AND (&), bitwise OR (|), bitwise XOR (^), and bitwise NOT (~).

6. Identity Operators
 - Checking object identity using is and is not (such as comparing integer and float representations).

7. Introduction to Strings
 - Initializing and printing string literals, starting with double quotes ("").
